# Host examples

- [Java host](java-host/README.md)
- [Node host](node-host/README.md)

Both command-line hosts run the Java-produced read-and-decide artifact through independently packaged runtimes and fake adapters. Completed/open/missing/wrong-resource cases demonstrate typed outcomes and separate DISPLAY consumption. Run the [combined verification](../conformance/read-and-decide/README.md#verify-both-runtimes-and-packaged-hosts). The full task-management application lives in the separate `keir-demo-app` repository.
