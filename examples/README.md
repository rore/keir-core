# Host examples

- [Java host](java-host/README.md)
- [Node host](node-host/README.md)

Both command-line hosts run Java-produced read-and-decide and single-effect artifacts through independently packaged runtimes and controlled adapters. Read examples demonstrate typed classification and DISPLAY consumption; [effect simulations](../conformance/single-effect/README.md) demonstrate conditional creation and EVENT_REPORT receipts for confirmed, skipped, rejected and uncertain outcomes. Run the [combined verification](../conformance/read-and-decide/README.md#verify-both-runtimes-and-packaged-hosts). The full task-management application remains deferred in the separate `keir-demo-app` repository.
