Core owns these guides and the roadmap for both repos. Verified Relay names select guidance, not assignments.

| Position | Relay name | Guide |
| --- | --- | --- |
| Manager | `@keir-manager` | [Manager](manager.md) |

| Documentation | `@keir-docs` | [Documentation](documentation.md) |

- Parallelize independently acceptable work and sequence dependent work. Mappings describe positions. Native subagents receive guides through their task brief and use native coordination.
- Resolve `mapping.yaml` and load the selected guide and [shared guidance](shared.md) as directed by [Core's role-loading instructions](../AGENTS.md). Other guides are on demand.
- If identity is unavailable, report it and continue only under independent task authorization; never guess/take over a name. Guides do not change established session settings.
- Keep temporary assignments/evidence in features and private operational details in ignored local notes. Role files contain durable responsibilities only.
