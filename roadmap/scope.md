# Current focus

This is the single roadmap for `keir-core` and `keir-demo-app`. Keir Core owns project direction, sequence and cross-repository acceptance. Implementation and tests stay in the repository whose code changes. Agent Workflow is proposed for core changes only at first; demo changes use ordinary PR review and tests. The demo needs no second roadmap or Work Record process.

First test whether one approved task catalog supports materially different customer requests without customer-specific host code. Next, measure a restricted CEL profile and execute one compiled artifact in both Java and Node. Then connect the Node runtime to a useful task application. The host-owned AI authoring experience follows the proven execution path.

The [design baseline](../docs/design-baseline/README.md) is historical input. Current decisions cover [repository boundaries](../docs/decisions/0001-repositories-and-runtimes.md), [product value](../docs/decisions/0002-product-proposition-and-evaluation.md) and [restricted CEL](../docs/decisions/0003-restricted-cel-resource-policy.md). Tool integration, GitHub publication, license and build choices remain open.
