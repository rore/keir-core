# Core 0.3.1 release and preparation record

Status: [Core 0.3.1](https://github.com/rore/keir-core/releases/tag/v0.3.1) was published on 2026-11-11 as a normal release in the private repository. Tag `v0.3.1` resolves to source `5c772d02b4dc92bb28ea8aedabd34498ff6d9391`. This record retains the original candidate preparation evidence and adds the verified distribution outcome. Publication does not change repository visibility or establish a live Daymark rollout.

This patch includes the reviewed CEL stack-exhaustion diagnostic fix, bounded Node canonical/admission work and cooperative Java expiry-thread hardening. The source language, model/artifact/scenario formats, environment pins, host authority and runtime limits are unchanged. Compiler identity is explicitly `keir-compiler-java/0.3.1`; it is not relabeled as 0.3.0.

Runtime 0.3.1 supports exactly the established artifact `/2` producer 0.2.0 and artifact `/3` producers 0.3.0 and 0.3.1 with matching model and environment pins. Unknown and cross-format producers are rejected. Historical `/1` data remains historical; this patch does not add `/1` execution support. Current `/3` fixtures are generated by the actual new compiler, while original 0.3.0 event and decision bytes are retained for both-runtime execution regressions.

The existing [release process](../releasing.md) governs asset construction, notices, checksums and installed Java/Node smoke. The selected Core source is [`5c772d02b4dc92bb28ea8aedabd34498ff6d9391`](https://github.com/rore/keir-core/commit/5c772d02b4dc92bb28ea8aedabd34498ff6d9391), merged by [PR #19](https://github.com/rore/keir-core/pull/19).
