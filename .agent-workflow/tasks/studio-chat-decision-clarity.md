## Design and technical plan

The standing designer selected the existing contextual canvas for full saved-change review, rather than a second large inline review surface. Chat holds questions, explanations, brief outcomes and purposeful links. New/returned discussions start with canvas closed; ordinary replies and background checks never open or replace it. A deliberate current-review link selects verified current work; historical example links remain historical and read-only. Current use, saved changes and uncertain outcomes must be distinguishable without repeated cards or procedural lectures.

The review sheet combines what the change does, what a representative task shows and the other checked examples. Approval remains independent of turning it on. After confirmed approval, the same sheet offers the separate named turn-on/switch consequence. Closing at any time returns to conversation. Completion remains a short confirmed receipt with a native-task return and a usable composer. Saved entry/return, later revision, deferred switch, reload and recovery are part of this same design, not follow-up polish.

The developer identified connected UI coaching and existing browser helpers that assume the automatic Current decision card. Update those expectations intentionally while retaining exact identity, permission, stale-response and selection assertions. Reuse existing canvas/open/close/review state and the actual approval/activation handlers; do not introduce a dismissal registry, workflow engine or alternate authority path.

Actual persona acceptance covers: new vague request through clarification, checked behavior, unrelated discussion, deliberate review, approval, separate use and native result; returning to active work, revising, preserving an unsent note through canvas changes, deferring switch and reloading; unsupported requests with consent before substitution; unknown/failure/stale/owner/history paths. Inspect desktop, phone and short windows, long content, zoom, keyboard focus/divider and scroll ownership. Tests complement actual rendered interaction and do not establish human visual acceptance.
