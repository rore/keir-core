Artifact admission must also compare artifact.compiler to the trusted host definition compiler; runtime support for both known producers must not silently admit the wrong producer under a selected host pin. New authoring remains 0.3.1 only; old pins are execution/history compatibility. Add consumer regressions for identity collision, mismatched producer, and old saved selections, with no native authority or transaction change.
