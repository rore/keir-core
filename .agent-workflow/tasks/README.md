# Agent Workflow Work Records

Save one `{slug}.md` per code, mixed-change or governance task in either Keir repo, using the installed skill's compact or expanded template according to risk/complexity. Share the record with delegated agents; do not create a record per agent or reuse `main.md`.

Documentation-only changes in configured `docs/`, `roadmap/`, `README.md` and `CONTRIBUTING.md` paths need no record. Instructions and policies remain workflow work. See the [current process](../../docs/internal/workflow/current-process.md) for applicability and demo commands.

On main, pass the explicit identity `agent-workflow:<slug>` to the resolver; validate using `--slug <slug>`. Run the resolver/checker against core even for demo work. Keep scope, reviews, verification and delivery state current; record actual evidence rather than backfilling fictional checkpoints. PRs are not required, CI findings remain advisory, and historical opt-in records retain their original meaning.
