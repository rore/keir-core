Fetch A through the existing owner-scoped evidence endpoint. Absent/ineligible/operator-only cases return null. A later B remains only Latest run until explicitly reapproved, including after remount. Preserve foreign-owner denial, current-draft identity, invalid-pin/proof rejection and existing selection/auth guards. No new endpoint, schema, mutation authority, runtime capability or reusable-Studio work is included. This resolves the discovered mechanism gap while preserving the original exact-reopen guarantee.
